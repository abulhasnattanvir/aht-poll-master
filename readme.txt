A lightweight WordPress plugin to create and manage interactive polls easily.

== Description ==

AHT Poll Master is a simple and flexible polling system for WordPress. It allows you to create unlimited polls and display them anywhere using a shortcode.

Engage your visitors with real-time voting and dynamic results display.

**Features:**
- Create unlimited polls
- Add multiple options per poll
- Display polls using shortcode
- Real-time voting system
- Percentage-based results
- Responsive design for all devices
- Admin dashboard for managing polls

== Installation ==

1. Upload the plugin to `/wp-content/plugins/aht-poll-master` or install via WordPress dashboard.
2. Activate the plugin through the 'Plugins' menu.
3. Go to **Poll System** in admin panel.
4. Create your first poll.
5. Use shortcode like:
   `[mpp_poll id="1"]`

== Frequently Asked Questions ==

= How do I display a poll? =
